# Who Bears the Error?

A reproducible empirical study of threshold choice, asymmetric classification
costs, and institutional accountability in COMPAS.

## Status

Work in progress.

This study extends an earlier expository analysis of COMPAS into an empirical
investigation. The research protocol is included in
`documentation/research_protocol.md`, with subsequent clarifications recorded
in `documentation/AMENDMENTS.md`.

The repository currently includes the core empirical analyses and manuscript
figures. Data and Methods, background and related work, and an integrated
working manuscript are also included.

Citation review, final reproducibility checks, manuscript formatting, and
public release preparation are still in progress.
